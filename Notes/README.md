# EmployeeAI Notes

This folder contains beginner-friendly explanations of technologies and concepts used in the project.

> **API keys:** EmployeeAI does not include Gemini/OpenAI credentials. Create your own keys and add them under **Settings → AI models** (or in `backend/.env`). See the [root README](../../README.md#add-your-own-api-key-required-for-ai).

Stack reminder (see `docs/Memory.md`): Next.js + Neon + Tailwind Soft UI (orange primary).

Every major note must answer:

1. What is this?
2. Why do we need it?
3. How does EmployeeAI use it?
4. How can a beginner see and try it?

Create notes when the corresponding feature is actually introduced.
