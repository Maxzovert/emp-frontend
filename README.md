# EmployeeAI Frontend

React (Vite) + React Router + Tailwind + GSAP.

## Setup

```bash
cd frontend
npm install
cp .env.example .env   # optional VITE_* flags
npm run dev
```

Dev server: http://localhost:5173 (proxies `/api` to http://localhost:3001)

## Scripts

| Command | Description |
|---|---|
| `npm run dev` | Vite dev server |
| `npm run build` | Production build to `dist/` |
| `npm run preview` | Preview production build |
